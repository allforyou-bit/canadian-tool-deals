# 사업자용 안내 (먼저 읽으세요)

이 폴더는 **"우리동네 홈케어"** 1인 홈서비스 사업을 시작하는 데 필요한 문서 전부입니다.
모든 숫자는 출처가 있거나 **추정/가정**으로 표시되어 있습니다. 표시가 없는 숫자를 발견하면 그대로 믿지 말고 확인하세요.

## 한 줄 요약

- **주력(트랙 A):** 가정용 청소(딥클린·입주·이사 청소·일반 청소 → 격주 정기 고객으로 전환). 차 없이도 가능.
- **추가(트랙 B):** 홈통 청소 + 수동 제설 시즌 계약. **관문(차량·사다리·서면 보험·예약 5건)을 통과할 때만** 켭니다.
- **안전망:** EI 자격이 있으면 **2026-10-10(토)까지 신청**. TaskRabbit·Jiffy에 첫날 지원(승인 시점·일감 양은 확인 안 됨).
- **기대치(추정):** 10월 $5,000은 불가능. 기본 시나리오에서 월 $5,000은 11–12월(트랙 B 포함) 또는 2027년 1월(청소만). 보수적 경우엔 1인으로 이번 겨울 내 도달 못 함. → [05-수익-시나리오.md](05-수익-시나리오.md)

## 첫날(9월 28일 월) 할 일

1. **체류 자격 확인(관문 0):** 캐나다에서 자영업을 할 수 있는 신분(시민권·영주권·자영업이 허용된 허가)인지 본인 서류로 확인. 불가하면 이 계획은 적용되지 않습니다.
2. [01-30일-실행계획.md](01-30일-실행계획.md)의 **첫날 질문 12개**에 답해 두기 (도시, 차량, 자금, 영어 편안함, EI 관련 정보 등).
3. TaskRabbit($25 등록비, 2차 출처)·Jiffy 지원.
4. Cloudflare 계정 만들고 사이트 배포 → [08-배포-가이드.md](08-배포-가이드.md). 연락처·동네 이름 입력.
5. 보험 중개사 3곳에 **영업배상책임보험(CGL)** 견적 요청 (질문 목록: [02-컴플라이언스-체크리스트.md](02-컴플라이언스-체크리스트.md)). **보험 가입 전에는 플랫폼 밖 직접 고객을 받지 않습니다.**
6. 실직일이 정해졌다면 EI 신청 일정 확정 → [03-EI-결정규칙.md](03-EI-결정규칙.md).
