# Checklist 02: Move-in / Move-out Clean (입주·이사 청소 체크리스트)

Track A. For an **empty** home or unit. Print one copy per job (작업마다 한 장씩 인쇄). It covers everything in the deep-clean column of `01-standard-and-deep-clean.md`, plus the items below. Anything not on this list is out of scope unless it is written on the quote (목록에 없는 작업은 견적서에 적혀 있을 때만 합니다).

Labels (표시): **ASSUMPTION/가정** = no source, measure it. **NOT VERIFIED/확인 필요** = not found or not checked in the research. "Memo" = `business/research/decision-memo.md`.

Job ID (작업 번호): ______ Date (날짜): ______ Beds/Baths (침실/욕실): ___ / ___ Add-ons on quote (견적서의 추가 옵션): ______________
Client / payer (고객·결제자): tenant / owner / property manager / realtor (세입자 / 집주인 / 관리회사 / 리얼터) ______ Hand-over deadline (집 인계 마감 시각): ______

## 1. When booking (예약할 때)

- [ ] Who is the client and who pays: tenant, owner, property manager or realtor? (고객과 결제자가 누구인지: 세입자, 집주인, 관리회사, 리얼터)
- [ ] The unit will be **empty**: movers finished before you arrive (집이 **비어 있는지**: 이삿짐이 먼저 다 나가야 합니다)
- [ ] Power, water and hot water will be on. If the power is off you cannot vacuum, so reschedule (전기, 물, 온수가 나오는지. 전기가 끊겼으면 청소기를 못 쓰니 날짜를 바꿉니다)
- [ ] Condo: building rules, elevator booking, where to park or unload, loading-dock hours (콘도: 관리 규정, 엘리베이터 예약, 주차·하차 위치)
- [ ] Who lets you in: a person on site, or a lockbox the client is responsible for. **No key custody in month 1** (memo §2) (출입: 현장에 사람이 있거나 고객 책임의 키박스. 첫 달에는 열쇠를 맡지 않습니다)
- [ ] Does the landlord or property manager have its own move-out checklist? Ask for a copy (집주인·관리회사 자체 체크리스트가 있으면 받기)
- [ ] Rush timing: jobs within 24 h, on weekends or on statutory holidays carry the rush premium in `config/prices.ts` (GTA default 15%, inside the 10–20% band in memo F18; it must match the live price book) (급한 일정: 24시간 내·주말·공휴일은 할증. GTA 기본값 15%, 실제 가격표와 같아야 합니다)
- [ ] Inside fridge, inside oven and inside empty cabinets are **add-ons** in the price book. Tell the client clearly whether they are on the quote (냉장고·오븐·빈 수납장 내부는 가격표상 **추가 옵션**입니다. 견적에 들어 있는지 고객에게 분명히 말합니다)
- [ ] CGL insurance bound before any off-platform job (memo §7, week 2) (플랫폼 밖 작업 전에 배상책임보험 가입)

## 2. On arrival (도착하면)

- [ ] Write the arrival time (도착 시각 기록)
- [ ] Confirm the unit is empty and utilities work. Test a light, a tap and the hot water (비어 있는지, 전기·물·온수가 되는지 직접 확인)
- [ ] **Before photos** of every room, bathroom fixtures, appliances, and close-ups of damage that was already there (walls, floors, counters), following `03-photo-protocol.md`. In a move-out these photos protect you in landlord–tenant disputes (작업 전 사진: 모든 방, 욕실 설비, 가전, 기존 파손 근접 사진. 이사 청소에서는 집주인과 세입자 사이 분쟁에서 오너를 보호합니다)
- [ ] Items left behind: do not throw anything away without the client's written OK by text. Junk removal is out of scope (남은 물건: 고객의 문자 확인 없이 버리지 않습니다. 짐 처리는 작업 범위가 아닙니다)
- [ ] Agreement signed. If signed **at the client's home in Ontario**: 10-day cancellation right, refund within 15 days (memo F32; effect of finishing the job within 10 days **not researched**). Not legal advice (계약서 서명. 온타리오에서 고객 집에서 서명하면 10일 취소권, 15일 내 환불. 10일 안에 작업을 끝낸 경우의 효과는 확인 필요. 법률 자문 아님)

## 3. Room by room: added to the deep-clean list (공간별: 딥클린 목록에 더하는 작업)

Do every **D** task from checklist 01 first, then these (체크리스트 01의 **D** 작업을 모두 하고 아래를 추가합니다).

### Every room (모든 방)

| Task (작업) | Done (완료) |
|---|---|
| Closets: shelves, rods, floor, inside of closet doors (옷장: 선반, 봉, 바닥, 문 안쪽) | [ ] |
| Walls: spot-clean marks with a damp cloth. Test a hidden spot first. No painting or patching (벽: 젖은 천으로 얼룩만 닦기. 안 보이는 곳에 먼저 시험. 페인트·보수 안 함) | [ ] |
| Switch plates and outlet covers: **dry cloth only** (스위치·콘센트 커버: **마른 천으로만**) | [ ] |
| Light fixtures you can reach from the floor or a small step stool (바닥이나 작은 발판에서 닿는 조명) | [ ] |
| Inside window glass, sills and tracks (실내 유리창, 창틀, 레일) | [ ] |
| Radiators or baseboard heaters dusted, only when turned off and cool (라디에이터·걸레받이 히터 먼지, 꺼져 있고 식었을 때만) | [ ] |
| Floors: vacuum edges and corners, then mop (바닥: 가장자리·구석 청소기 후 물걸레) | [ ] |

### Kitchen (주방)

| Task (작업) | Done (완료) |
|---|---|
| Outside of all cabinets, top to bottom, including the tops if reachable (모든 수납장 겉면, 위에서 아래로, 손 닿으면 윗면까지) | [ ] |
| Inside cabinets and drawers: **only if the "inside empty cabinets" add-on is on the quote** (수납장·서랍 내부: **"빈 수납장 내부" 옵션이 견적에 있을 때만**) | [ ] |
| Inside fridge: **add-on only**. Unplugging is the client's call; leave the door ajar only if they ask (냉장고 내부: **옵션일 때만**. 전원을 끌지는 고객이 정합니다) | [ ] |
| Inside oven: **add-on only**. Ventilate well if you use oven cleaner (오븐 내부: **옵션일 때만**. 오븐 세제를 쓰면 환기) | [ ] |
| Behind and under the stove and fridge: only if they roll out easily and the client agrees (레인지·냉장고 뒤와 밑: 쉽게 빠지고 고객이 동의할 때만) | [ ] |
| Around the sink drain wiped; no plumbing work (싱크대 배수구 주변 닦기. 배관 작업은 안 함) | [ ] |

### Bathrooms (욕실)

| Task (작업) | Done (완료) |
|---|---|
| Inside vanity drawers and cabinet: **add-on only** ("inside empty cabinets") (세면대 서랍·수납장 내부: **옵션일 때만**) | [ ] |
| Medicine cabinet inside, if empty (약장 내부, 비어 있을 때) | [ ] |
| Light fixture and exhaust fan cover (조명, 환풍기 커버) | [ ] |

### Outside the unit (집 밖)

| Task (작업) | Done (완료) |
|---|---|
| Condo balcony: sweep only, no hose or pressure washer (콘도 발코니: 쓸기만, 호스·고압 세척기 안 씀) | [ ] |
| Garbage and recycling out per building or city rules (쓰레기·재활용은 건물·시 규정대로 배출) | [ ] |

### Not included: decline politely (포함되지 않는 작업: 정중히 거절)

- Junk removal or hauling (짐 처리·운반)
- Painting, wall patching, repairs of any kind (페인트, 벽 보수, 모든 수리)
- Plumbing, gas, electrical (memo §3) (배관·가스·전기)
- Exterior windows; pressure washing (memo §3) (외부 유리창, 고압 세척)
- Carpet shampooing or steam cleaning (owner choice) (카펫 샴푸·스팀 청소: 오너 판단)

## 4. Before you leave the job (마치기 전)

- [ ] **After photos** from the same angles: each room from the doorway, open closets, appliances, bathrooms. Share them only with the client who hired you; sending them to anyone else (landlord, realtor) needs that client's OK (작업 후 사진: 같은 각도로. 사진은 의뢰한 고객에게만 보내고, 다른 사람(집주인, 리얼터)에게 보내려면 그 고객의 동의가 필요합니다)
- [ ] All lights off, taps off, windows locked, door locked, lockbox closed (불·수도 끄기, 창문·현관 잠금, 키박스 닫기)
- [ ] Payment received and receipt given; split amounts above bank e-Transfer limits (memo F36) (결제와 영수증. 은행 e-Transfer 한도를 넘으면 나눠 받기)
- [ ] Realtor or property-manager client: ask if they have another unit coming up (리얼터·관리회사 고객이면 다음 집이 있는지 묻기)
- [ ] Write the finish time (종료 시각 기록)

## 5. Supply kit (준비물)

Take the portable kit from checklist 01, section 5, plus (체크리스트 01의 5절 준비물에 더해):

- [ ] Extra microfibre cloths and melamine sponges; empty units take more (여분 극세사 행주와 멜라민 스펀지. 빈 집은 더 많이 씁니다)
- [ ] Heavy-duty garbage bags (두꺼운 쓰레기봉투)
- [ ] Oven cleaner and a scraper, only when the oven add-on is booked (오븐 세제와 스크레이퍼, 오븐 옵션이 있을 때만)
- [ ] Headlamp for closets and dim rooms (옷장과 어두운 방용 헤드램프)
- [ ] Your own vacuum: an empty unit usually has none (본인 청소기: 빈 집에는 보통 없습니다)

Supply costs were **not found** in the research; the memo's 20% of ticket is an ASSUMPTION (A2) (준비물 비용은 조사에서 찾지 못했습니다. 매출의 20%는 가정입니다).

## 6. Time log (시간 기록)

The memo assumes 5 h per flat-rate clean (A1, ASSUMPTION). Move-outs will likely differ from deep cleans, so log them separately and compare (메모는 정액 청소 1건에 5시간으로 가정합니다(가정). 이사 청소는 딥클린과 다를 수 있으니 따로 기록해 비교합니다).

| Job ID | Beds/Baths | Add-ons | Rush Y/N | Left home | Arrived | Finished | Home | On-site h | Travel h | Supplies $ | Transit/parking $ | Price $ |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  |  |  |

Effective $/h = (Price − Supplies − Transit/parking) ÷ (On-site h + Travel h). Copy each line to the CRM jobs tab (실제 시급 = (가격 − 준비물 − 교통·주차) ÷ (현장 + 이동 시간). 매 줄을 CRM 작업 탭에 옮겨 적습니다).
