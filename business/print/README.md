# 인쇄물 PDF

이 폴더의 PDF는 **설정 입력 전 샘플**입니다. 전화번호가 비어 있고, QR 코드가 임시 주소(`example.pages.dev`)를 가리키며,
빨간 "SAMPLE" 워터마크가 찍혀 있습니다. **그대로 인쇄해 배포하지 마세요.**

## 실제 인쇄용 만드는 법 (둘 중 하나)

1. **가장 쉬운 방법:** 사이트를 실제 설정(전화, 이메일, 우편 주소, 동네 이름, 사이트 주소)으로 배포한 뒤
   브라우저에서 `https://<내 사이트>/print/` (한국어는 `/ko/print/`)를 열고 → 원하는 인쇄물 → 인쇄
   (레터 용지, 배율 100%, "페이지에 맞추기" 해제). 설정이 모두 들어가면 워터마크는 자동으로 사라집니다.
2. **PDF로 다시 만들기:** 설정을 환경변수로 넣고 `npm run build` → `npm run pdf`
   (Playwright 필요: `npm i -D playwright && npx playwright install chromium`).

## 파일

| 파일 | 내용 |
|---|---|
| `door-hanger-{en,ko}-{c1,c2,c3}.pdf` | 문고리 전단, 레터 1장에 2개. c1–c3은 동네(클러스터)별 QR (`/quote/?src=c1` 등) |
| `flyer-{en,ko}-{c1,c2,c3}.pdf` | 반쪽 전단, 레터 1장에 2개 |
| `price-sheet-{en,ko}.pdf` | 가격표 (켜진 서비스만 표시) |
| `agreement-{cleaning,gutters,snow}-{en,ko}.pdf` | 서비스 계약서 양식 — 법률 자문 아님, 사용 전 변호사·보험사 검토. 홈통 청소·제설 계약서는 그 서비스를 켰을 때만 사이트에 게시됩니다. 여기 있는 홈통·제설 PDF는 서비스를 켜기 **전에** 보험 중개인·변호사에게 검토받으라고 미리 만든 양식입니다(`PDF_ONLY='agreement-(gutters\|snow)'`로 두 서비스를 켠 빌드에서 생성) |

인쇄 비용·인쇄소는 조사하지 않았습니다(확인 필요).
